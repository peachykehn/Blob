# Blob
A speaker is a magnet, so I got a big speaker solenoid and put it behind some ferrofluid to make it dance.
The bass is boosted because the ferrofluid blob should dance following the rhythm of the bass rather than the treble, like humans. 
This is version 1.0 which has too many nixie tubes (apparently there is such a thing). It also did not fit together quite right. But it works until the next iteration is complete. <img width="800" height="885" alt="blob" src="https://github.com/user-attachments/assets/e0773319-b498-4d68-9b46-85ef702b445f" />

Sound input needs to be amplified significantly to power all two IN-9 tubes, two 1X 6E1P tubes and a 500 newton solenoid. The signal is split and a 10k potentiometer is placed at the end of each because each device picks up the audio signal differently, so adjustment is required.
